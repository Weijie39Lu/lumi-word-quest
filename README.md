# Lumi Word Quest · U1 原型

这是一个无需安装、面向 iPad Safari 的 Power Up 1 Unit 1–9 单词小游戏原型。

## 当前内容

- U1–U9 九个主题、413 个核心词汇与重点短语；
- 翻卡学词、中文配对、缺字母拼写三种玩法；
- iPad 可用的英语发音按钮；
- 星星、连胜和“答对 3 次即掌握”的本地进度保存；
- 认读和拼写分别以 1、2、4、7、15、30 天的间隔循环复习；
- 每正确拼写 10 次，解锁一张不同样式的原创 Lumi 拼写之星贴纸；
- 原创魔法萌宠 Lumi（不使用现有 IP 角色）。

## 在电脑上打开

在本文件夹运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。

## 在 iPad 上试玩

1. 让 iPad 与电脑连接同一个 Wi-Fi。
2. 使用电脑的局域网地址加端口 `8000` 打开本游戏。
3. 在 iPad Safari 点击“分享”，选择“添加到主屏幕”。

正式给孩子长期使用前，建议将它发布为 HTTPS 网页；届时可正常离线安装、保存进度。
